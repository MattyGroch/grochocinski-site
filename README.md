# matt.grochocin.ski

Matt Grochocinski's personal page, served by GitHub Pages at https://matt.grochocin.ski.

- `index.html`: the whole page, with no build step. Each project tile opens a dialog with a description and screenshots.
- `shots/`: project screenshots (WebP, named `project-view.webp`).
- `avatar.webp`, `og.jpg`: the pixel-art portrait (page avatar and link preview).
- `CNAME`: the custom domain.

`grochocin.ski` and `www.grochocin.ski` redirect here from the home server (Traefik).
